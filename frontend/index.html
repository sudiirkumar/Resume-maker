How to use this app

Quick instructions for offline, cloud, and AI workflows

Quick start

  1. Fill in your details in the left panel. The preview on the right updates as you type.
  2. Use + Add buttons to add more education, projects, achievements, interests, skills, and other sections.
  3. When ready, use Print / Save PDF to download the resume as a PDF.

Offline use with JSON

You can use the app completely offline by saving your form data as JSON and restoring it later.

  • Download JSON creates a backup file of everything in the form.
  • Upload JSON lets you bring back a previously saved file and continue editing.

The achievements and interests sections are saved as bullet-style lists, so every visible row is preserved in the JSON file and restored exactly as you left it.

Example: finish your resume on one laptop, download the JSON file, and upload it later on another device to continue from the same data.

Cloud save

If you want your resume stored online, use Cloud Sync / Login to sign in, then save your data to the cloud.

  • Sign Up creates your account.
  • Log In unlocks cloud sync and loading your saved resume.
  • Load latest resume from cloud restores the last saved resume.
  • Logout ends the cloud session on this browser.
  • Save to Cloud keeps your latest data online for easy access from anywhere.

Example: make changes at work, save to the cloud, and later load the same resume on your home computer without retyping everything.

AI assistance

The AI tools are available in two places:

  • The small star button appears next to eligible paragraph fields when you click inside them. Use it for Proofread, Professional rewrite, and Summary.
  • The Resume AI button at the bottom-left opens resume-wide ATS suggestions.

Resume AI can review the whole resume for ATS fit, keyword coverage, impact, and conciseness. It ignores personal details, education rows, and footer content when building the review context.

Helpful tips

  • Use real, consistent dates and spellings for the best final PDF.
  • Upload images only when needed, since large files can slow things down.
  • Achievements and interests behave like bullet lists, so add one idea per row for the cleanest preview.
  • For AI suggestions, review the output before applying it, especially on long descriptions.
  • Keep a JSON backup before making big edits so you can roll back quickly.
